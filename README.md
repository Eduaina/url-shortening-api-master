# URL Shortening API Landing Page

## Overview
A responsive landing page that integrates with the CleanURI API to shorten URLs, manage shortened links, and persist data in the browser.

## Features
- Shorten valid URLs using CleanURI API
- Display list of shortened links
- Copy shortened links to clipboard
- Persistent storage using localStorage
- Input validation with error handling
- Fully responsive layout (mobile-first)

## Tech Stack
- HTML5 (semantic structure)
- Bootstrap 5 (layout & responsiveness)
- Vanilla JavaScript (DOM manipulation + API integration)

## Implementation Notes
- No page reloads during interactions
- Links persist after browser refresh using localStorage
- Bootstrap grid system used for responsive layout structure
- External CSS used for design refinement
